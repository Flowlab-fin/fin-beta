# Flow Lab Fin beta

Surf fin design software by Flow Lab, for invited testers.

## Get started (Windows 10 / 11)
1. Download **FlowLabFin-beta-0.1.0.exe** from the file list above. No install, no Python needed. It opens in its own window and keeps working offline for up to 7 days at a time.
2. Double-click it. If Windows says *"Windows protected your PC"*, click **More info**, then **Run anyway**.
3. Type your email and click **Check**. Click **Ask PK for access**: it sends PK your email and your computer's code.
4. When PK has added you, click **Check** again and the app opens. Your licence runs 30 days; PK can extend it.

If Windows blocks the program outright (Smart App Control), turn it off in Windows Security > App & browser control, or ask PK for help.

## Problems and ideas
Use **Send feedback** in the app's top bar, or email info@keylinecomposites.com.
If something goes wrong, the app writes `flowlab-fin-errors.log` beside the program: please attach it.

`status.json` is the beta's signed licence list (no names or emails in it).
